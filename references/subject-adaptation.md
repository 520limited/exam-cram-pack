# 学科适配：不同课程怎么变

八部分骨架不变，但**每个学科的"分析工具"和"答题模板"形态不同**。先判学科类型，再套对应写法。

判型只看一件事：**这门课考试要学生"做什么"**。

---

## A 论述型（思政 / 法学 / 文史哲 / 教育学 / 管理学理论）

**识别信号**：全是论述/材料分析/简答；要"结合材料""联系实际""谈谈你的理解"；答案靠论点+论证，不靠计算。

**核心改造**：
- 命题主线往往是"理论主题"（如实践与求真、矛盾分析、世界历史）
- 答题模板 = **论点递进式**（破题 → 理论 → 分层 → 实际 → 收束）
- 必背金句 = **经典引文**（马恩原话、法条原文、史家论断）
- 联系实际素材库 = **时政/案例**，必须具体到政策名称
- 阅卷逻辑重点讲"理论准确性"和"是否落到实际"

**易错**：通篇堆砌、没有分析框架、联系实际写口号。

---

## B 计算型（数学 / 物理 / 计算机 / 电子 / 统计）

**识别信号**：有公式、数值、推导；题型含计算/证明/求值。

**核心改造**：
- 命题主线改为"**题型族**"（如极限求法、级数判敛、矩阵对角化）——按**解法**归并，不按章节
- 第三部分每个考点必须含：**识别信号 → 适用公式 → 标准步骤 → 典型例题（带完整推导）→ 易错点**
- 答题模板 = **解题流程**（识别 → 选法 → 列式 → 求解 → 检验）
- 必背金句 → **必背公式/定理表**（含使用条件，条件写错等于不会）
- 模拟卷必须给**完整解答**，不能只给要点
- 阅卷逻辑重点讲"步骤分"：中间步骤写出来就有分

**易错**：只给结论不给条件、公式记混适用条件、跳步。

---

## C 语言型（英语 / 二外）

**识别信号**：词汇、语法、翻译、写作、听力。

**核心改造**：
- 命题主线按"题型"：完形/阅读/翻译/写作
- 第三部分考点 = 语法点 + 高频词族 + 典型句式
- 答题模板 = 写作框架（三段式/图表描述/议论文）、翻译步骤
- 必背金句 → **万能句型 + 过渡句**
- 联系实际素材库 → 写作素材（人物、事件、数据）
- 模拟卷含完整范文

---

## D 实务型（工程 / 医学 / 财会 / 法律实务）

**识别信号**：有流程、规程、案例分析、分录、诊断。

**核心改造**：
- 命题主线按"业务流程/病种/业务类型"
- 第三部分考点 = 流程步骤（编号）+ 判定标准 + 典型案例
- 答题模板 = **决策树/流程式**（判断 → 分支 → 处置）
- 必背金句 → **规范条文/操作要点**
- 联系实际素材库 → 真实案例（脱敏）

---

## E 混合型

很多课是混合的（如经济学：既有曲线推导，又有学派人物）。
**按模块分别判型**，不同章用不同写法，不要强行统一。

在第二部分章节表里加一列"类型"，标明每章属 A/B/C/D。

---

## 判型后的三个影响

| 影响 | 说明 |
|---|---|
| 篇幅分配 | 论述型按真题频率；计算型按题型出现率 |
| 模板形态 | 论述用段落式；计算用流程式；实务用决策式 |
| 附录写法 | 论述型给"参考答案"；计算型给"完整解答"；语言型给"范文" |

---

## 通用不变的几条

无论哪类学科，以下恒定：

1. 真题优先，按知识点/题型**归并**而非按年份罗列
2. 每个考点都要有"考法提示"
3. 可背表述加粗
4. 联系实际/举例必须具体
5. 模拟卷必须是新题
6. 附录覆盖全部年份
