# 质量闸门：交付前自检清单

逐条打勾。**任一条不过，不算交付完成。**

---

## 一、结构完整性

- [ ] 封面含：课程名、副标题、依据材料（文件名+页数+类型）、生成日期
- [ ] 使用说明含：三档时间路径 + 标记说明
- [ ] 八部分齐全，标题顺序正确
- [ ] 附录覆盖材料中出现的**全部**年份
- [ ] 目录可跳转（如导出 PDF）

## 二、第一部分（考情分析）

- [ ] 题型结构有一句话结论（不是只给表）
- [ ] 有「年份 × 题号 × 考查内容」表
- [ ] 命题主线 4—7 条，**按知识点归并而非按年份罗列**
- [ ] 每条主线都有「已考题目」和「还可能怎么考」两列
- [ ] 「还可能怎么考」写的是新情境，不是重复已考题
- [ ] 阅卷逻辑给了三条判据 + 一个分值配比
- [ ] 判据里有本课的具体例子（不是泛泛而谈）

## 三、第二部分（逻辑链）

- [ ] 有一句话把全部章节用箭头串起来
- [ ] 章节表含「核心方法 / 一句话 / 回答什么问题」
- [ ] 有记忆口诀
- [ ] 口诀说明用法（"答题时先报用哪一章的方法"）

## 四、第三部分（逐章考点）

- [ ] 编号连续（1.1、1.2…2.1…），无跳号
- [ ] **每个考点都有"考法提示"**
- [ ] 对比类内容用表格
- [ ] 关键表述加粗
- [ ] 有真题的标了 `真题 YYYY`
- [ ] 每章末尾有「本章自测」（2—3 题）
- [ ] **篇幅按真题频率分配**（高频章明显更长）

## 五、第四部分（答题模板）

- [ ] 模板数量 = 命题主线数量（±1）
- [ ] 开头有"模板的用法"（不要整段照抄）
- [ ] 每个模板有「题目特征」
- [ ] 每个模板分段 4—5 段，每段有明确功能名
- [ ] 每段内容能落笔（不是"要辩证分析"这种空话）
- [ ] 每个模板有「联系实际」和「一句话收束」
- [ ] 模板之间有区分度，不是同一个套路换名字

## 六、第五部分（速记表）

- [ ] 纯表格，两列：概念 | 一句话定义
- [ ] 定义 ≤ 40 字
- [ ] 20—40 条
- [ ] 只收考试会写到的概念

## 七、第六部分（金句）

- [ ] 15—20 条
- [ ] **全部是真实引文**（不是 AI 造的）
- [ ] 出处能确认的写了出处，确认不了的写作者
- [ ] 没有编造页码

## 八、第七部分（模拟卷）

- [ ] **是新题**（不是搬真题）
- [ ] 题型与分值严格匹配真题
- [ ] 每题有「参考答案要点」，5—8 个分层编号
- [ ] 开头有限时建议与评分标准

## 九、第八部分（考场策略）

- [ ] 时间表（审题/提纲/作答/检查）
- [ ] 万能段落模板
- [ ] 素材库 10—15 条，**每条有具体政策名/事件/数据**
- [ ] 失分点 8—10 条，具体带数字或对比
- [ ] 最后 N 天日程

## 十、附录（真题答案）

- [ ] 覆盖全部年份
- [ ] 每题有「答题思路」（用哪把刀）
- [ ] 每题有分段「参考答案」
- [ ] 每题有「一句话收束」
- [ ] 答案不是教材原文照抄

## 十一、证据规范

- [ ] 每个 `真题 YYYY` 都能在真题文件里找到对应题
- [ ] 每个 `补` 标在 AI 补充内容上
- [ ] 加粗只用于"可背表述"
- [ ] 没有编造的页码/篇目
- [ ] 无 OCR 的扫描件已在"依据材料"里注明

## 十二、可用性

- [ ] 只看第五、六部分，能应付考前 2 小时
- [ ] 只看第一、四部分，能知道每类题怎么写
- [ ] 随便抽一道真题，能在模板部分找到对应套路

---

## 自动检查

```bash
python scripts/check_pack.py <复习资料.md>
```

覆盖：八部分标题、真题标注格式、金句条数、模板数量、素材库条数、未标注的补充内容。

人工还需核对：内容准确性、可落笔程度、篇幅分配合理性。
