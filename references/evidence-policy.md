# 证据政策：标注规范与防编造

这份文件解决一件事：**让读者随时能分辨哪句话是材料里的，哪句是 AI 补的。**

---

## 一、证据分层

材料按权威性排序，**高优先级的覆盖低优先级**：

```
1. 历年真题        ← 最高，决定"考什么"
2. 课程重点/老师划的重点
3. 课件/讲义
4. 教材
5. AI 补充         ← 最低，必须标记
```

冲突处理：
- 教材说 A、重点说 B → **用重点的**（更贴近本课口径），但可在正文提一句"教材另有表述"。
- 重点说 A、真题考的是 B → **两者都保留**，真题决定"考什么"，重点决定"怎么写"。
- 无法判断 → 标 `推断`，说明依据。

---

## 二、四种标记

### 2.1 `真题 YYYY`
**何时用**：该考点确实在某年真题出现过，且能指到具体年份。

格式：`〔真题 2024〕`、`〔真题 2020 / 2023〕`

**何时不能用**：
- 只是"可能考" → 用 `推断`
- 只是思考题里有 → 不能标真题，要写"思考题覆盖"
- 不确定哪一年 → 写 `〔真题（年份待核）〕` 或直接省略

### 2.2 `补`
**何时用**：AI 补充的时政、案例、延伸素材，**教材没有原话**。

典型场景：
- 联系实际段落里的政策名称（"新质生产力""枫桥经验"）
- 教材版本较旧，需要补最新表述
- 考试要求"联系实际"但材料里没有案例

格式：段落末尾标 `补`。

### 2.3 `推断`
**何时用**：无真题覆盖，但依据材料结构/重点分布/章节篇幅推断为高频。

必须写明依据。例：
> 〔推断：本章为重点文件中的独立一节，且与真题 2024 考点相邻〕

### 2.4 `【待核】`
**何时用**：内容存疑，但为了完整性先写、请用户核对。

典型场景：
- 引文出处记不准
- 扫描件识别不清
- 不同材料表述矛盾且无法判断

---

## 三、加粗 = 可背表述

全篇 `**加粗**` 语义固定：**可以直接背下来写进卷面的表述**。

所以：
- 不要给"提示性语言"加粗（如"注意这里""重点看"）
- 不要给标题加粗（标题自带层级）
- 只给"能直接默写到卷面上的句子"加粗

这条规则让学生扫一眼就知道背哪句。

---

## 四、引文处理

### 能确认出处
```
"社会生活在本质上是实践的。"（马克思《关于费尔巴哈的提纲》）
```

### 记不清具体篇目
```
"……"（马克思）
```

### 完全不确定是不是原话
**不要加引号**。改写为：
```
马克思认为，社会生活在本质上是实践的。
```

### 绝对禁止
- 编造页码（"第 123 页"）
- 编造篇目（把《德意志意识形态》的话安到《资本论》）
- 把 AI 生成的话加上引号和出处

## 五、真题的处理

### 有真题文件
必须**逐题读完**，不允许只看标题。因为：
- 真题的设问方式决定模板形态
- 真题的分值决定篇幅分配
- 真题的重复率决定主线数量

### 真题是第一手材料
引用真题题干时，**照抄原文**（可缩写但不可改写设问）。因为学生要对着原题复习。

### 真题年份不全
如材料只有 2020/2023/2024/2025：
- 附录只写这四年，**不要编 2021/2022**
- 第一部分写"2020—2025 年（材料提供四套）"

---

## 六、扫描件的处理

### 判断
```bash
python scripts/extract_materials.py --probe <文件>
```
输出 `text_layer: yes/no` 与 `images` 数量。

### 有文字层
直接抽。

### 无文字层（纯图片）
1. **用视觉能力读**，不要要求用户 OCR
2. 优先读：目录页、每章首页与末页、图表页
3. 页数多时不必逐页精读——教材通常只是"核对表述"用
4. 识别不清的段落标 `【待核】`，不要猜

### 重要提醒
**重点文件与真题文件通常有文字层**，它们才是骨架。教材扫描件缺失内容不会致命——只要声明"教材仅作核对"。

---

## 七、自检三问

交付前，对全文问三遍：

1. **随便挑一个 `真题 YYYY` 标注，能在真题文件里找到对应题目吗？** 找不到就是编的。
2. **随便挑一条加粗的表述，是教材/重点里的原话或接近原话吗？** 差太远要改回普通字体。
3. **随便挑一段"联系实际"，里面有一个具体政策名称/事件/数据吗？** 全是"要坚持""要推进"就是口号，重写。
