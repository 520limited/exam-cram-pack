# 使用说明

这份资料只解决一个问题：**把材料的内容变成考场上能写出来的答案**。
它按"考情—框架—考点—模板—速记—模拟"的顺序编排，不同时间压力下的用法不同。

**剩余时间怎么用**

| 剩余时间 | 只看这些 |
|---|---|
| 3 天以上 | 第三部分逐章过一遍，每章做完"自测"；再背第四部分模板、第六部分金句 |
| 1—2 天 | 第一（考情）、第四（模板）、第五（速记表）、第六（金句）+ 第七（模拟卷） |
| 考前 2 小时 | 第五（速记表）、第六（金句）、第八部分的"联系实际素材库" |

**标记说明**：**加粗**的是可以直接背下来写进卷面的表述；标有 `真题` 的是历年考过的原题考点；标有 `补` 的是结合时政补充的素材，材料没有原话，用于"联系实际"。
